# Prerequisite

## Fedora

- Full 5GB Latex
```sh
sudo dnf upgrade --refresh
sudo dnf install -y git make gcc-c++ python3 texlive-scheme-full
```

- Minimalist

sudo dnf install -y \
  git \
  make \
  gcc-c++ \
  python3 \
  texlive \
  texlive-extsizes \
  texlive-listings \
  texlive-framed \
  texlive-geometry \
  texlive-tools \
  texlive-fancyhdr \
  texlive-amsmath \
  texlive-amsfonts \
  texlive-tocloft \
  texlive-titlesec \
  texlive-psnfss \
  texlive-graphics \
  texlive-paralist \
